# 小说灵感库（轻量版）

这里是你写小说的“灵感收集与整理”位置：先**快速记录**，再**定期整理**。

## 推荐工作流

1. **随手记**：任何灵感先写进 `inbox.md`（不要停下来打磨）。
2. **每日/每周整理一次**：
   - 把可用灵感复制成条目（用 `entry_template.md` 的格式）
   - 按主题分段放回 `inbox.md` 里对应的小节（或另建文件也行）
3. **写作时检索**：用关键词（人物名/地点/意象/冲突）快速查找。

## 文件说明

- `inbox.md`：唯一入口，所有灵感先丢这里
- `entry_template.md`：可复制粘贴的条目模板

## 小技巧（真的有用）

- 记录时尽量写清 **冲突/欲望/代价**，它们最能转化成情节。
- 每条灵感都补一行“**如果要写成一章，会发生什么？**”
