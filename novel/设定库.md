## 1. 世界基调

- 时代 / 地点：近未来或架空现代；高科技军事与科研发达，同时面临生物威胁与能源紧张。
- 表面日常：高中、城市、媒体新闻；年轻人仍谈论机甲、空军、漫画模型。
- 冲突层如何存在：
  - **表面**：能源危机；邻国国力强盛但资源短缺，暗中制造摩擦以吞并他国。
  - **暗中**：北极冰川实验室发掘出异形；其作为天生文明毁灭者，以寄生伪装与筑巢进化吞噬人类世界。
- 时代主轴：**高科技对抗生物兵器**。
- 情绪关键词：天空、机甲、冰川、伪装、能源告急。

## 3. 机甲分类

### 3.1 总表

| 类型 | 体量 / 外观 | 运作方式 | 社会门槛 | 辨识特征 |
|------|-------------|----------|----------|----------|
| **大型机甲** | 约十层楼高 | 驾驶舱操控的重型机体 | 军方 / 国家战力为主（细则待定） | 城市尺度的压迫感；海报与模型的常见主角 |
| **小型机甲** | 外骨骼形态，比人体略大 | 穿戴强化，人机一体机动 | 相对常见的单兵 / 特种用途（细则待定） | 外壳轮廓仍可读出「人」的比例 |
| **贴身机甲** | 外观看起来像普通衣服 | 纳米机器引导人体做高精度动作 | **造价昂贵，通常仅顶尖贵族可能配备** | 高功率运行时，看似装饰的**宝石位置会发光** |

### 3.2 细则

#### 大型机甲

- 体量：一般约十层楼高。
- 叙事功能：战场主力、天空与地面的战略存在感；最容易成为少年海报上的「梦」。
- 等级归属：**将 / 王**（大型机甲默认「将」，核阈规格才称「王」）。
- 待补：动力来源、武器模块、是否具备飞行型号、与空军编制的对应关系。

#### 小型机甲（外骨骼）

- 体量：外骨骼机甲，整体比人体型略大。
- 叙事功能：单兵强化、城市战、登舰/登大型机甲的过渡形态。
- 等级归属：**兵 / 骑士**。
- 待补：续航、防护上限、与生物兵器交锋时的优劣。

#### 贴身机甲

- 外观：常态下与普通衣服无异，可隐蔽于社交场合。
- 原理：通过**纳米机器**引导人体，实现高精度动作。
- 造价与归属：极其昂贵；**只有顶尖贵族才有可能配备**。
- 高功率特征：运行功率拉高时，衣服上看来只是装饰的**宝石会发光**——既是性能指示，也是身份暴露风险。
- 等级归属：**兵 / 骑士**（贵重≠将/王；高功率常见骑士）。
- 叙事功能：阶级差距可视化；「看起来只是衣服」的信息不对称；发光宝石可作为识破/高潮镜头。
- 待补：宝石颜色与功率档位是否对应、纳米失控副作用、贵族以外的非法仿制品是否存在。

### 3.3 与主角梦想的关系（暂定）

- 主角口头/海报上的「驾驶机甲自由飞行」，当前更贴近**大型机甲（飞行型号）**的想象。
- 实际入门路径更可能先接触**小型外骨骼**相关机械与软件。
- **贴身机甲**属于另一阶级的世界，开局不可轻易获得。

## 3A. 等级制度（按破坏力）

> 原则：等级只回答「能破坏到什么规模」，不直接等同造价、稀有度或社会地位。

### 3A.1 机甲四级：王 · 将 · 骑士 · 兵

> 官方机甲用语。排序：**兵 < 骑士 < 将 < 王**。  
> 分界：**兵 / 骑士** = 大型机甲以下（贴身、小型外骨骼等）；**将** = 大型机甲；**王** = 核阈级。

| 等级 | 破坏力（简单口径） | 机甲对标（约） |
|------|--------------------|----------------|
| **兵** | **伤人～破屋**：击倒人员，毁车辆/墙体/小工事 | 入门外骨骼、低功率贴身 |
| **骑士** | **裂街～摧区**：夷平街区局部至瘫痪城区一角；大型以下顶格 | 精锐～顶级小型/贴身 |
| **将** | **破城～倾邦**：摧毁城区防区，乃至撼动一国战区部署 | **大型机甲**（约十层楼）主力与王牌 |
| **王** | **核阈**：核弹级毁伤 | 终极战略机甲；对标异形**巨兽**能量攻击 |

- 口诀：**骑士封顶地面人机，将开十层楼的天，王是核弹那一格。**
- 「王」极稀；巨兽能量攻击按破坏力**对标王级**，但巨兽本身不是机甲。

### 3A.2 辅助口径：D / C / B / A（非机甲）

> 用于人、枪械、天然/人造异形个体等**非机甲**单位；与机甲四级大致对照，避免混叫。

| 辅助级 | 破坏力 | 约对机甲四级 |
|--------|--------|--------------|
| **D** | 伤人级 | ≈ 兵（低） |
| **C** | 破屋级 | ≈ 兵（高） |
| **B** | 裂街级 | ≈ 骑士（低） |
| **A** | 摧区级 | ≈ 骑士（高） |

- 排序：**D < C < B < A**。
- 不要说「A 级大型机甲」——大型机甲应称**将**（或极罕**王**）。

### 3A.3 速查对照

| 对象 | 用哪套 | 常见落点 |
|------|--------|----------|
| 普通人 / 常规枪械 | D–C | D～C |
| 贴身机甲 | 机甲四级 | 兵～骑士 |
| 小型外骨骼机甲 | 机甲四级 | 兵～骑士 |
| 人造异形（个体） | D–A | 视型号 |
| 天然异形杂兵 / 特化兵 | D–A | 杂兵 C～B，特化可到 A |
| 大型机甲 | 机甲四级 | **将** |
| 异形巨兽（能量） | 对标 | **王** |

### 3A.4 禁忌

- 不要用兵/骑士形容大型机甲；不要用将/王形容外骨骼单兵。
- 不要把 ABCD 直接喊在机甲型号上（应称兵/骑士/将/王）。
- 等级只量破坏力：贵族贴身可以是「骑士」却不是「将」；巨兽可以没有机甲外壳却对标「王」。

## 4. 角色设定卡

### 陆航（主角）

- **身份**：普通高中生；中国名。
- **外观要点**：清爽普通少年感（细节待补）；寝室像小型机甲展。
- **能力 / 专长**：刻意加强机械、软件科目；收藏并研究机甲相关模型、海报、漫画；后期驱动 **AI 不断进化**以分析天然异形真名。
- **欲望**：驾驶机甲自由在天空飞行；加入空军成为驾驶员。
- **恐惧**：飞不起来 / 世界在自己起飞前先崩塌。
- **关键道具**：捡到白色笔记本，命名为**缚灵笔记**（详见专节）。
- **晋升通道**：意外展露驾驶天赋后，被**神秘公司**破格录取 → 严训 → 实习再证 → 危机中职位快速上升。
- **弧光**：机甲梦与苦练 → 意外展天赋 → 公司培养与晋升 → 成长为传奇 → 知母体不可灭尽 → 击杀巨兽取星球之名 → 定住母体，为人类争生存机会。
- **私密空间**：家中卧室贴满机械作品海报，并有模型与漫画。

### 神秘公司（名称待定）

- **功能**：在非常规路径下发掘、录取、训练机甲驾驶员；陆航的破格通道。
- **待定**：是否即霍尔特集团、军方白手套、或独立第三方；与邻国战、异形战的立场。
- **叙事功能**：把「高中生空军梦」接进专业战场与快速晋升。

### 米歇尔·布兰特（Michel Brandt）

- **身份**：男性；外国名。与陆航关系：待定（同学 / 战友 / 同行者均可）。
- **外观要点**：帅气；**金发**。
- **性格表层**：喜欢撩妹；表面**放荡不羁**，玩世不恭。
- **性格内里**：其实**不敢真正表达自己的感情**；轻浮是外壳，认真是禁区。
- **能力 / 专长**：**擅长狙击**（远距精准杀伤；战场定位偏远程支援 / 猎杀）。
- **欲望**：被看见真实的自己，却又主动躲开被看见。
- **恐惧**：认真之后被拒绝 / 失去游刃有余的人设。
- **弧光方向（暂定）**：撩与逃 → 危机中不得不托付真心 → 狙击镜后第一次不躲闪。
- **叙事功能**：提供轻佻对照与远程火力；用「敢撩不敢爱」制造感情线张力。
- **待补**：国籍/阵营、与陆航如何相识、狙击武器与机甲协同方式、是否卷入缚灵笔记/寄生线。

### 艾拉·霍尔特（Ella Holt）· 公司千金

- **身份**：外国名；**霍尔特集团**千金（集团偏城市安防 / 权限系统 / 民用监控与特种科技，易咬合「科技制裁」）。
- **核心动机**：因**幼年悲剧**，走上用**科技制裁罪犯**的道路。
- **幼年悲剧（蝙蝠侠式）**：幼年与父母看完演出后抄小路回家，遭遇持械抢劫；父母为护她遭枪杀，她躲在死角幸存。从此「秩序崩在一条巷子里」成为执念原点。
- **手段倾向**：不靠披风私刑，而靠技术优势——监控回放、行踪锁定、账户/门禁/载具权限冻结、数据链围堵等，把罪犯置于可控制裁之下（细则待定）。
- **性格底色（暂定）**：外表冷静得体；内里执念强，正义感与阴影并存；对「来不及」三个字过敏。
- **与主线咬合点（可选）**：资源/技术赞助；与陆航软件专长、缚灵笔记、人造异形、机甲体系产生合作或冲突；制裁名单撞上被寄生者（写名无效）时世界观崩一层。
- **欲望**：让巷子里的悲剧不再发生；让罪犯付出代价。
- **恐惧 / 代价**：执念吞噬自身；科技制裁越过法律与人道边界；发现有些「罪犯」里已经没有人。
- **弧光方向（暂定）**：复仇式制裁 → 直面系统与异形更大的恶 → 选择「制裁」还是「守护」。
- **待补**：与米歇尔/陆航的关系、是否本人上阵还是幕后操盘、霍尔特集团与军方/邻国的利益关系。

### 异形（种族设定，名称待定）

- **本质**：天生的**文明毁灭者**（非可沟通文明）。
- **来源（故事内）**：北极冰川实验室意外发掘后逸出。
- **欲望（本能表述）**：猎杀、寄生、扩张，直至吞噬/毁灭人类文明；无主观「野心独白」。
- **弧光**：实验室逸出 → 寄生伪装渗透 → 数量阈值后筑巢 → 适应性军备升级 → 巨兽级战略打击 → **揭示星球即母体**。
- **详细规则**：见下一节「异形设定」。
- **终局位格**：个体/巢/巨兽皆为表象；人类栖居的星球本身是异形母体——故「无法战胜」指无法根除，只能争取定身窗口。

### 人造异形（中期人类造物）

- **定位**：人类为对抗天然异形而发明的特殊战力 / 实验体。
- **构成**：拥有**人类的意识** + **异形的各种能力**。
- **缺陷**：容易**反叛**。
- **与缚灵笔记**：其名字主角**可以获取**（因而可被写名定身）——是中期突破「真名死结」的特殊方式。
- **叙事功能**：给人可用的「可定身异形」；同时埋下反叛的人祸线，与天然异形威胁叠压。
- **待补**：制造原理、谁主导项目、反叛动机、与巢/天然异形的互相识别。

### 邻国（国名待定）

- **定位**：相邻国家；国力强盛，资源短缺。
- **行为**：暗中制造摩擦，意图吞并其他国家。
- **叙事功能**：表面世界危机的可见推手；可遮盖或被异形暗线利用（关系待定）。

## 5. 异形设定

### 5.1 本质与意识

- 天生的**文明毁灭者**。
- **本体没有意识，无法交流**；不会谈判、不会结盟、不会表达自我。
- 行为驱动：**本能猎杀**其他生物。
- 看似「有谋略」的部分，全部来自**盗用宿主的人格与知识**去搜寻敌人弱点——是寄生机能，不是异形自身觉醒了智慧。

### 5.2 寄生与伪装

| 能力 | 说明 |
|------|------|
| 寄生 | 可寄生其他生物 |
| 伪装 | 可伪装成宿主外形混入其社会关系 |
| 夺取 | 获取宿主的**知识**与**能力** |
| 劣势策略 | 局势不利时，本能驱动其**维持宿主伪装、潜伏等待机会** |
| 优势策略 | 利用宿主人格/知识分析对手弱点，再以本能完成猎杀与扩散 |

- 北极开局案例：实验室人员被寄生/清空后，异形以「其中一员」之姿离开，混入人类社会。
- 注意：它「说话像某人」，是因为在跑宿主人格数据，不是异形学会了做人。

### 5.3 繁殖

1. **产卵**。
2. 卵中**寄生虫**发育成熟。
3. 寄生虫钻入目标体内，**迅速完成寄生**。
4. 关键恐怖点：宿主**甚至不会察觉**自己已被寄生。

### 5.4 巢与适应性进化

- **筑巢阈值**：异形数量达到一定规模后，会制造**巢**。
- 巢的功能：
  1. **快速生产**更多异形；
  2. 根据已获得的**信息**，提升周围异形的**适应性**；
  3. 可进化出**特殊武器**与**高级兵种**。
- **情报升级范例**（已定逻辑）：
  - 某异形获取到**枪械**相关数据 → 巢为附近异形升级**反制枪械**的能力；
  - 表现可包括：威力更强的**远程攻击**手段；
  - 以及能轻松击杀士兵的**高级兵种**。
- 延伸含义（待写战例）：若巢吃到机甲 / 外骨骼 / 贴身机甲数据，理论上也可演化对应反制——与「高科技对抗生物兵器」主轴直接对撞。

### 5.5 巨兽（数量再增后的战略进化）

- **触发**：异形数量进一步增多时，会进化出**巨兽**。
- **能力**：
  1. **力量巨大**（物理层面可碾压常规部队与部分机甲编制，细则待写）；
  2. 能产生**核弹级别的能量攻击**（战略威慑 / 毁城级打击）。
- **叙事功能**：把危机从「战场吃紧」推到「文明存亡」；大型机甲与空军的存在理由被硬性抬高。
- **终局关键**：陆航击杀巨兽后，得以取得**星球真名**（兑换机制待定）。
- **与巢的关系（暂定）**：巨兽多在种群与巢体系成熟后出现；是否必须由巢「孵化/组装」待定，但需有数量门槛铺垫。
- **待补**：体量与大型机甲（约十层楼）的对比、能量攻击的蓄力征兆、可否被轨道武器/王牌机甲拦截、击杀后如何析出星球之名。

### 5.5b 星球母体（终局真相）

- 人类所在星球 = **异形母体**。
- 含义：歼灭地表异形无法结束战争；母体层不可被常规武力「杀死」。
- 人类胜利条件改写：不是灭尽，而是取得星球真名并以缚灵笔记**定住母体**，换取生存时间/空间。
- 情绪定位：绝望底牌 + 传奇窗口；避免假大空「一拳打爆星球」。

## 6. 缚灵笔记

### 6.1 来历与命名

- 主角**捡到**一本**白色笔记本**。
- 首页有奇怪描述，大意：在笔记本上**写下某个名字**，对应之人就会被**定身**。
- 主角将其命名为：**缚灵笔记**。

### 6.2 基础规则

| 规则 | 说明 |
|------|------|
| 写名定身 | 写下目标的名字 → 该目标被定身 |
| 真名指向 | 生效对象是「名字所代表的那个存在」本身 |
| 对寄生失效 | 若目标已被异形寄生，写**宿主人类名**无法定身 |
| 对虫生效 | 必须写下**寄生异形的名字（真名）**，才能定住真正的支配者 |
| 真名稀缺 | 异形无意识、不可交流，真名几乎无法从对话或常规情报获取 |

### 6.3 识破寄生（关键剧情功能）

- 主角**无意中发现**：有些人写下名字后毫无反应。
- 推论：这些人不是「笔记坏了」，而是**已被寄生**——壳还是人名，里面的支配者另有其名。
- 缚灵笔记因此成为早期、个人向的**测谎仪 / 筛寄生工具**（写名无效 = 高度可疑）。

### 6.4 真名获取路径

| 阶段 | 路径 | 对象 | 说明 |
|------|------|------|------|
| 早期 | 几乎无解 | 天然异形 | 无意识、不可交流，常规手段拿不到真名 |
| **中期** | **人造异形** | 人造个体 | 人类发明；有人意识 + 异形能力；**易反叛**；**名字主角可以获取** |
| **后期** | **进化 AI** | 天然异形 | 不断进化的 AI 分析出真名，才能稳定定身天然寄生者 |
| **终局** | **击杀巨兽** | **星球母体** | 取得**星球真名** → 写入笔记 → **定住母体**，换生存机会 |

#### 人造异形（特殊取名方式）

- 人类在中期发明**人造异形**，试图把异形能力纳入己用。
- 特性：人类意识 + 异形诸能力；代价是**容易反叛**。
- 关键：因其具备可称呼、可登记、可被人知晓的「名字」，主角能把名字写入缚灵笔记并定身——这是中期唯一稳定的「对异形能力单位写名」突破口。
- 注意：人造异形 ≠ 天然异形；能定住人造个体，**不自动等于**已掌握天然异形真名。天然线仍要等后期 AI。

#### 进化 AI（后期）

- 障碍：天然异形只有本能，无法交流 → 不能靠审问、谈判、诱供拿到真名。
- 路径：主角凭借软件方向积累，推动 **AI 不断进化**，最终能**分析出天然异形真名**。
- 叙事咬合：机械/软件专长从「考空军加分项」升级为对抗无意识敌人的钥匙；亦可参与解析星球之名。

#### 星球真名（终局）

- 前提：揭开「星球 = 母体」；击杀巨兽。
- 效果：星球之名写入缚灵笔记 → 定住母体级存在 → 人类获得生存窗口。
- 禁忌：这不是灭世胜利；是传奇争取到的暂停键。
- 待补：定身持续多久、母体被定住后地表异形如何、名字字形/信息形态。

### 6.5 禁忌与待补

- 不要把笔记写成万能杀伤；已定效果是**定身**（后续是否可升级待定）。
- 不要让主角开局就能批量写出**天然**异形真名；天然真名绑定后期 AI。
- 人造异形可中期取名，但须付出「易反叛」的戏剧代价；不可写成完美忠犬兵种。
- 星球真名仅属终局；不可提前用「写地球」秒杀。
- 待补：笔记本来源与制作方、定身持续时间/解除条件、错写名字的副作用、AI 进化阶段划分、人造异形命名权归谁、反叛后名字是否仍有效、白色封面是否有其他页规则、神秘公司全称。

## 9. 禁忌与一致性

- 不要开局就让陆航成为王牌驾驶员；保持「普通高中生苦练」起点，天赋靠意外与再证两次钉死。
- 不要开局配备贴身机甲；该档仅顶尖贵族可能拥有。
- 描写机甲时核对档位：兵/骑士=大型以下；将=大型；王=核阈。
- 贴身机甲高功率时宝石必须发光；低功率/待机可保持「普通衣服」外观。
- **禁止**把异形写成可交流、可谈判、有自我意识的角色；「像人」只来自宿主人格盗用。
- 劣势时优先写**伪装潜伏**，而非无脑硬刚；优势/猎杀时回归本能残酷。
- 巢出现前，不要大规模投放「高级特化兵种」；特化需有情报来源铺垫（如先接触枪械数据）。
- 巨兽出现前，需有异形数量显著增多的铺垫；核弹级攻击不可变成开局随便放的招式。
- 宿主可被寄生而无察觉——相关「突然反水」桥段需符合此规则。
- **写宿主名无法定身已被寄生者**；唯异形真名有效——此条与无意识、不可交流设定绑定。
- **天然**异形真名获取走**后期进化 AI**；**中期**仅人造异形名字可被主角稳定获取；**星球真名**仅终局、经巨兽一战。
- 终局禁止写成「人类灭尽异形」；正确收束是**定住母体、争取生存**。
- 人造异形必须保留**易反叛**；不要写成无代价的完美解决方案。
- 不要过早把异形真相对全社会公开；维持双层危机的信息差；母体真相更要压到终盘。
- 邻国扩张要有「资源短缺」逻辑，避免写成无动机纯反派。
- 机甲与生物对抗的技术规则确定后，战斗描写需前后一致。
