## 1. 世界基调

- 时代 / 地点：近未来或架空现代；高科技军事与科研发达，同时面临生物威胁与能源紧张。
- 表面日常：高中、城市、媒体新闻；年轻人仍谈论机甲、空军、漫画模型。
- 冲突层如何存在：
  - **表面**：能源危机；邻国国力强盛但资源短缺，暗中制造摩擦以吞并他国。
  - **暗中**：北极冰川实验室发掘出异形；其作为天生文明毁灭者，以寄生伪装与筑巢进化吞噬人类世界。
- 时代主轴：**高科技对抗生物兵器**。
- 情绪关键词：天空、机甲、冰川、伪装、能源告急。

## 3. 机甲分类

### 3.1 总表

| 类型 | 体量 / 外观 | 运作方式 | 社会门槛 | 辨识特征 |
|------|-------------|----------|----------|----------|
| **大型机甲** | 约十层楼高 | 驾驶舱操控的重型机体 | 军方 / 国家战力为主（细则待定） | 城市尺度的压迫感；海报与模型的常见主角 |
| **小型机甲** | 外骨骼形态，比人体略大 | 穿戴强化，人机一体机动 | 相对常见的单兵 / 特种用途（细则待定） | 外壳轮廓仍可读出「人」的比例 |
| **贴身机甲** | 外观看起来像普通衣服 | 纳米机器引导人体做高精度动作 | **造价昂贵，通常仅顶尖贵族可能配备** | 高功率运行时，看似装饰的**宝石位置会发光** |

### 3.2 细则

#### 大型机甲

- 体量：一般约十层楼高。
- 叙事功能：战场主力、天空与地面的战略存在感；最容易成为少年海报上的「梦」。
- 待补：动力来源、武器模块、是否具备飞行型号、与空军编制的对应关系。

#### 小型机甲（外骨骼）

- 体量：外骨骼机甲，整体比人体型略大。
- 叙事功能：单兵强化、城市战、登舰/登大型机甲的过渡形态。
- 待补：续航、防护上限、与生物兵器交锋时的优劣。

#### 贴身机甲

- 外观：常态下与普通衣服无异，可隐蔽于社交场合。
- 原理：通过**纳米机器**引导人体，实现高精度动作。
- 造价与归属：极其昂贵；**只有顶尖贵族才有可能配备**。
- 高功率特征：运行功率拉高时，衣服上看来只是装饰的**宝石会发光**——既是性能指示，也是身份暴露风险。
- 叙事功能：阶级差距可视化；「看起来只是衣服」的信息不对称；发光宝石可作为识破/高潮镜头。
- 待补：宝石颜色与功率档位是否对应、纳米失控副作用、贵族以外的非法仿制品是否存在。

### 3.3 与主角梦想的关系（暂定）

- 主角口头/海报上的「驾驶机甲自由飞行」，当前更贴近**大型机甲（飞行型号）**的想象。
- 实际入门路径更可能先接触**小型外骨骼**相关机械与软件。
- **贴身机甲**属于另一阶级的世界，开局不可轻易获得。

## 5. 异形设定

### 5.1 本质与意识

- 天生的**文明毁灭者**。
- **本体没有意识，无法交流**；不会谈判、不会结盟、不会表达自我。
- 行为驱动：**本能猎杀**其他生物。
- 看似「有谋略」的部分，全部来自**盗用宿主的人格与知识**去搜寻敌人弱点——是寄生机能，不是异形自身觉醒了智慧。

### 5.2 寄生与伪装

| 能力 | 说明 |
|------|------|
| 寄生 | 可寄生其他生物 |
| 伪装 | 可伪装成宿主外形混入其社会关系 |
| 夺取 | 获取宿主的**知识**与**能力** |
| 劣势策略 | 局势不利时，本能驱动其**维持宿主伪装、潜伏等待机会** |
| 优势策略 | 利用宿主人格/知识分析对手弱点，再以本能完成猎杀与扩散 |

- 北极开局案例：实验室人员被寄生/清空后，异形以「其中一员」之姿离开，混入人类社会。
- 注意：它「说话像某人」，是因为在跑宿主人格数据，不是异形学会了做人。

### 5.3 繁殖

1. **产卵**。
2. 卵中**寄生虫**发育成熟。
3. 寄生虫钻入目标体内，**迅速完成寄生**。
4. 关键恐怖点：宿主**甚至不会察觉**自己已被寄生。

### 5.4 巢与适应性进化

- **筑巢阈值**：异形数量达到一定规模后，会制造**巢**。
- 巢的功能：
  1. **快速生产**更多异形；
  2. 根据已获得的**信息**，提升周围异形的**适应性**；
  3. 可进化出**特殊武器**与**高级兵种**。
- **情报升级范例**（已定逻辑）：
  - 某异形获取到**枪械**相关数据 → 巢为附近异形升级**反制枪械**的能力；
  - 表现可包括：威力更强的**远程攻击**手段；
  - 以及能轻松击杀士兵的**高级兵种**。
- 延伸含义（待写战例）：若巢吃到机甲 / 外骨骼 / 贴身机甲数据，理论上也可演化对应反制——与「高科技对抗生物兵器」主轴直接对撞。

### 5.5 威胁层级（叙事用）

| 阶段 | 状态 | 人类侧观感 |
|------|------|-------------|
| I | 单体 / 少数，寄生伪装 | 「失踪」「生还者神情不对」 |
| II | 无察觉扩散（卵与寄生） | 疫点、内部崩坏，原因不明 |
| III | 筑巢 + 情报进化 | 常规火力失效；出现特化兵种 |
| IV | 文明级侵蚀 | 高科技武器体系被迫全面升级 |

## 7. 时间线（故事内）

1. T0：异形在北极实验室被发掘 → 寄生/清除人员 → 伪装混入人类社会（暗线已启动）。
2. T1：主角高中日常；能源危机与邻国摩擦成为公开议题（表面危机升温）。
3. T2：异形隐蔽产卵扩散；局部异常难以归因。
4. T3：数量达阈值后筑巢；开始针对人类武器情报进化（两线交汇加压）。

## 8. 禁忌与一致性

- 不要开局就让主角成为王牌驾驶员；保持「普通高中生」起点。
- 不要开局配备贴身机甲；该档仅顶尖贵族可能拥有。
- 描写机甲时核对档位：十层楼高 = 大型；略大于人体 = 小型外骨骼；像衣服 = 贴身。
- 贴身机甲高功率时宝石必须发光；低功率/待机可保持「普通衣服」外观。
- **禁止**把异形写成可交流、可谈判、有自我意识的角色；「像人」只来自宿主人格盗用。
- 劣势时优先写**伪装潜伏**，而非无脑硬刚；优势/猎杀时回归本能残酷。
- 巢出现前，不要大规模投放「高级特化兵种」；特化需有情报来源铺垫（如先接触枪械数据）。
- 宿主可被寄生而无察觉——相关「突然反水」桥段需符合此规则。
- 不要过早把异形真相对全社会公开；维持双层危机的信息差。
- 邻国扩张要有「资源短缺」逻辑，避免写成无动机纯反派。
- 机甲与生物对抗的技术规则确定后，战斗描写需前后一致。
