> 主项目：《怪雨人偶》。附录为独立短篇《诅咒之地》。

## A. 《怪雨人偶》

### A1. 世界基调

- 现代中国校园，表面日常。
- 超自然层以「怪雨」形式侵入，不公开、不联网热搜式传播，多为个案与都市传说。
- 情绪关键词：潮湿、瓷冷、半张脸、认得。

### A2. 怪雨规则（硬设定）

| 编号 | 规则 | 备注 |
|------|------|------|
| R1 | 雨落在皮肤上，该部位瞬间失去知觉与自主控制（「抽空」） | 非麻痹痛感 |
| R2 | 随后皮肤转为瓷质人偶材质，纹理消失，触感微凉 | 可有釉光 |
| R3 | **停驻型**：变化止于被淋范围（例：林叙右臂） | 原因未明 |
| R4 | **蔓延型**：瓷化分界线持续向未淋区域推进（例：顾晚晴） | 雨停后仍可蔓延 |
| R5 | 意识全程清醒；蔓延者能感知身体被「改写」 | 核心恐怖来源 |
| R6 | 常规医疗、保温、盐、火等无法逆转；最多短暂延缓 | 第二幕验证 |
| R7 | 瓷裂纹中可出现「人偶心跳」，节奏可与远方降雨对齐 | 中点钩子 |
| R8 | 蔓延过半后，瓷化侧可能发出非本人语气的话语 | 规则层在「试用」壳 |
| R9 | 怪雨本质接近「收藏意识的工艺」：把活人装进不腐的壳 | 第三幕真相 |
| R10 | 「名字 / 认得」可作为对抗改写的锚点（机制待细化） | 结局关键 |

### A3. 角色设定卡

#### 林叙

- **身份**：高中生；男主。
- **外观要点**：普通；常备廉价折叠伞。
- **异变**：右臂停驻型瓷化 / 失灵。
- **欲望**：保住顾晚晴；弄清规则。
- **恐惧**：认不出她；或她不再认自己。
- **弧光**：被动护人 → 主动用残缺身体对抗规则。

#### 顾晚晴

- **身份**：同校；众人眼中的校花。
- **外观要点**：干净、浅色衣着；异变后半身瓷光、半脸假面。
- **异变**：左半身起蔓延型人偶化；左腕裂纹；人偶心跳。
- **欲望**：证明「我还是我」。
- **恐惧**：醒着看自己变成物件。
- **弧光**：被改写的恐惧 → 与瓷身谈判 / 争夺主导权。

### A4. 地点设定

| 地点 | 功能 | 感官要点 |
|------|------|----------|
| 湖边小道 | 开场约会 / 怪雨初降 | 碎金路灯、蝉停 |
| 廊亭 | 第一幕高潮庇护所 | 柱影、砸雨、石凳冰凉 |
| 校园（日常） | 第二幕调查 | 晚自习灯、传闻、剪报 |
| 源头（待定） | 终局对决 | 候选：废弃温室 / 旧湖心亭 / 地下管廊 |

**源头候选决议标准**：需能陈列「成品人偶」、与水/雨有关、校园可抵达。

### A5. 时间线（故事内）

1. T0：约会黄昏，雨降。
2. T0+数分钟：廊亭，蔓延开始，裂纹心跳。
3. T1（雨后数日）：调查旧案，延缓失败。
4. T2：瓷侧代言，远方再雨。
5. T3：抵达源头，对决与命名。

### A6. 禁忌与一致性

- 不要把怪雨写成可随意召唤的魔法攻击。
- 不要让人偶化变成单纯战斗强化（除非第三幕明确交易）。
- 林叙与顾晚晴的类型差异必须有伏笔，不可无故互换。
- 对白中「认得 / 名字」一旦使用，后续需有代价或反噬可能。

## B. 附录 · 《诅咒之地》（独立设定，勿与 A 混用）

### B1. 一句话

三人误入诅咒林地，精灵留下印记：一女触衣则溃、一女断吻则绝；惩罚同时觉醒为极速与控气。

### B2. 规则摘要

| 对象 | 诅咒 | 觉醒能力 |
|------|------|----------|
| 苏晚 | 皮肤触衣 → 剧痒至腐烂 | 极速移动（近瞬移残影） |
| 沈清禾 | 须不断与异性接吻续气，否则窒息 | 操控气流（风鞭、风墙、探路） |
| 陈昭 | 玉佩挡下自身诅咒 | 无对应能力；责任是护不住旁人的愧疚与决策 |

### B3. 敌与出口

- 狼形咒兽：皮毛下符文；败后化青烟。
- 雾墙裂口外：更浓的黑暗（续写钩子）。
