> 一句话卖点：高中生**陆航**一心要开上将级机甲飞上天；意外展露驾驶天赋后被神秘公司破格录取，在危机中一路攀升——直到发现整颗星球只是异形母体。人类无法彻底战胜，他却以传奇之姿击杀巨兽、取得星球之名，用缚灵笔记定住母体，为人类争得一线生机。

## 1. 核心引擎

- **主角脊梁**：机甲梦 → 苦练 → 意外事件展天赋 → 神秘公司破格录取 → 严训 → 实习再爆天赋 → 危机中快速晋升 → 终局真相与定住星球。
- **并行压力**：邻国能源战（表面）× 异形寄生/巢/巨兽（暗中）× 缚灵笔记真名死结。
- **终局解法**：击杀巨兽 → 获得**星球真名** → 写入缚灵笔记 → **定住星球级异形母体** → 人类获得生存窗口（非彻底灭虫）。
- 未解/待咬合：神秘公司是谁（是否霍尔特或另立）？笔记从哪来？星球之名与 AI/巨兽的具体兑换关系？

## 3. 主角线（陆航 · 正式故事脊梁）

| 阶段 | 节点 | 内容 | 战力/职位感（约） |
|------|------|------|-------------------|
| **I** | 机甲梦 | 高中生；寝室海报墙；志向空军/将级机甲天空 | 无编制 |
| **II** | 苦练 | 平时极度重视机械、软件、模拟与相关练习 | 夯实基本功 |
| **III** | 意外事件 | 遭遇某事件（与异形/摩擦/事故相关，具体待定） | 被迫上手 |
| **IV** | 天赋展露 | 展现**驾驶机甲的战斗天赋** | 一战成名苗头 |
| **V** | 破格录取 | 被**神秘公司**破格录取（非寻常高考/空军路径） | 进入专业体系 |
| **VI** | 严训 | 接受更专业、更严格的训练 | 兵→骑士阶磨砺 |
| **VII** | 实习再证 | **实习考试**遇意外，再次展示天赋 | 巩固「不是运气」 |
| **VIII** | 危机晋升 | 不断遇危机、不断成长，**职位快速上升** | 骑士→将；触摸王级战场 |
| **IX** | 终局真相 | 发现惊人真相：**星球只是异形的母体**；人类无法彻底战胜 | 传奇位 |
| **X** | 传奇收束 | 击杀**巨兽** → 取得**星球之名** → 缚灵笔记定住星球异形 → **为人类争取到生存机会** | 以名定母体 |

### 与奇物/异形线的咬合（建议落点）

- **I–II**：可并行捡到缚灵笔记、初验定身；苦练含软件，为后期 AI 埋伏。
- **III–IV**：意外事件最好同时逼出「寄生/异形」与「机甲上手」。
- **V–VII**：神秘公司提供机甲与情报；实习意外可叠人造异形或巢初显。
- **VIII**：职位上升 ↔ 战场升级（巢、情报进化、将级机体）。
- **IX–X**：AI/巨兽情报最终指向「星球真名」；笔记从定人、定虫，升到**定住母体**。

## 4. 分卷结构（按主角线排）

### 第一卷 · 梦与意外（阶段 I–IV）

1. 建立陆航机甲梦与苦练日常；邻国摩擦作背景音。
2. 缚灵笔记入手与写名无效（寄生钩子）可插在苦练段。
3. **意外事件**爆发 → 陆航被迫/得以驾驶机甲 → **战斗天赋**暴露。
4. 卷末：神秘公司伸出橄榄枝——**破格录取**。

### 第二卷 · 公司与再证（阶段 V–VII）

1. 入职神秘公司；专业严训；认识/深化米歇尔、艾拉关系。
2. 真名死结加深；人造异形登场（可获名）；邻国与暗线交织。
3. **实习考试**遇意外，陆航再度展天赋，坐实破格不是偶然。
4. 卷末：第一次正式编制/职位跃迁；巢或大规模寄生露头。

### 第三卷 · 上升与崩坏（阶段 VIII）

1. 危机连环：巢进化、反制枪械、人造异形反叛、将级作战。
2. 陆航职位快速上升；驾驶将级机甲成为可能。
3. 中点低谷：常规胜利无效；意识到「杀不完」。
4. 卷末：巨兽级威胁逼近；真相碎片指向「这颗星球不对」。

### 第四卷 · 母体与定名（阶段 IX–X）

1. 惊人真相：**星球 = 异形母体**；人类无法以歼灭取胜。
2. 陆航成长为传奇；决战巨兽并击杀。
3. 自巨兽/战场取得**星球之名**（具体机制待定：AI 解析 / 巨兽核心 / 笔记共鸣等）。
4. 将星球之名写入缚灵笔记 → **定住母体** → 人类获得生存窗口（开放式希望，非灭世大团圆）。

## 5. 主题与情绪

- 主题：飞向天空的梦，对上无法根除的母体；**传奇不是赢光一切，而是争到明天**。
- 情绪曲线：热望 → 苦练 → 意外高光 → 公司压迫成长 → 危机上瘾式上升 → 真相绝望 → 定名后的艰难生机。
- 核心意象：海报天空、驾驶舱、职位章、巨兽、星球之名落笔、母体一滞。
